# Quantiva — Responsive Landing Page

A modern, responsive startup landing page developed as **Task 01** of the SkillCraft Technology Web Development Internship.

## Project Overview

Quantiva is a fictional technology brand landing page designed with a clean, professional interface, a light blue and white colour palette, and interactive navigation.

## Features

- Responsive layout for desktop and mobile screens
- Fixed navigation bar
- Navigation styling changes when scrolling
- Interactive hover effects
- Mobile navigation menu
- Hero, Services, About, and Contact sections
- Smooth animations and interactive elements

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

## Project Files

- `index.html` — Website structure and content
- `style.css` — Styling, responsive design, and animations
- `script.js` — Navigation behaviour and interactive functionality
